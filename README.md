# sysadmin-learning-journal

This repository is intended to be a collection of notes regarding my learning experiences as a system administrator at [Decidim-RS](https://github.com/Fklippel/Decidim_RS.git). Here I will be registering my first steps as a beginner, common cheatsheets for general usage, and general practices, using the book Unix and Linux System Administration Handbook by Evi Nemeth, Garth Snyder, Trent R. Hein, Ben Whaley, and Dan Mackin as a reference.
Feel free to explore, and pull requests with corrections or suggestions are welcome.
